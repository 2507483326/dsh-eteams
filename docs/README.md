# dsh-eteams 设计文档集

`dsh-eteams` 是面向 DeepSeek Harness（DSH）的多智能体团队协作插件：用户选择团队模式后，由领队（Captain）把目标拆解为任务清单并全程协调，成员（Member）各司其职执行任务；每个成员使用 vue-color-avatar 风格头像；所有任务状态、执行线路与中断恢复都以磁盘持久化为准，进程重启后可继续。

本目录是插件 v0.2 的完整设计基线。文档按主题拆分，单一文档只回答一个问题；跨文档的结论以本文的「决策记录」为准。

## 术语速查

- **DSH**：DeepSeek Harness，宿主运行时（Web GUI / Desktop / Headless）。
- **Profile**：DSH 的组合配置（`desktop` / `web`…），插件通过 `cordis.patch.yml` 挂载进 profile。
- **领队 / Captain**：创建团队的会话主智能体。只负责拆解、指派、协调与汇报，不执行任务（D4）。
- **成员 / Member**：领队派生出的可续聊子智能体（durable continuable subagent），执行具体任务，可各自配置模型。
- **任务 / Task**：工作单元，含合同（目标、验收、范围）、依赖与状态。
- **尝试 / Attempt**：任务的一次执行记录；重试、换人、恢复都会产生新尝试。
- **执行线路 / 执行记录**：任务下按时间排列的尝试与事件时间线，UI 直接渲染（见 [06](06-task-lifecycle.md)）。
- **执行链 / Chain**：任务预规划的成员执行路线（站点序列：成员 + 阶段说明）；默认分配沿链推进，特殊情况领队偏离并留痕（D11）。
- **站点 / Station**：执行链中的一站：某成员对该任务的一段职责切片；站点完成推进游标，末站完成即任务完成。
- **人设 / Persona**：成员的固定框架画像（角色定位/职责/风格/技能/纪律/执行提示），内容可修改（D13）。
- **任务文件夹 / Work Dir**：团队工作目录（`<workspace>/teams/<team-slug>/`，可配置），存放 README、任务合同与执行笔记等 MD 文档（D12）。
- **执行槽 / Slot**：任务行内联的执行链站点槽位（完成✔/当前●/待执行◌/空槽虚线），支持拖拽成员入槽分配（D14）。
- **成员对话框 / Member Dialog**：面板内与成员的双向消息视图：进度汇报、任务提问、用户直发与答复（D15）。
- **成员库 / Roster**：工作区级可复用成员定义（`.eteams/roster.json`，D16）：按名 upsert，各团队引用入库并复制人设。
- **邮箱 / Mailbox**：领队与成员间的持久化点对点消息（JSONL 追加）。
- **状态根 / State Root**：`<workspace>/.eteams/`，全部团队状态的磁盘真相。
- **staged 计划**：团队启动前的草案阶段：成员与任务可编辑，用户显式批准后才正式运行。

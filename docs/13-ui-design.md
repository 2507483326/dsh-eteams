UI 原则（承接 [03](03-tech-stack.md) 3.4）：只渲染不决策；磁盘快照是唯一数据源；复用宿主原语与主题（亮/暗/材质）；文案随宿主 locale（中/英）。

## 13.2 对话卡片（ETeamsCard）

每个团队在对话流中出现一张卡片（团队创建时插入；点开历史会话仍可重渲染）：

- 头部：领队头像（种子生成，风格同成员）+ 团队名 + 阶段徽标（草案/运行中/已暂停/待决策/已完成/已归档）。
- 中部：成员头像行（点击头像 -> 打开该成员子代理会话记录，跳转复用宿主 subagent 视图）；进度条（completed/total）。
- 尾部：最新一条事件摘要（如「研究员 完成 t1 竞品矩阵」）+「打开面板」按钮（window 事件唤起浮动面板，模式同参考实现）。
- 待决策时卡片头部加黄点 + 决策数角标。

## 13.3 浮动活动面板（ActivityPanel）

右侧浮动、可拖拽宽度（记忆位置）、可关闭；空态（无团队）显示「创建团队」引导。顶部：

- **团队切换器**：活动团队 ▾ 下拉列出本会话全部团队（阶段徽标 + 进度），含「新建团队」「归档团队」入口（D3）。
- **决策横幅**：`pendingDecisions` 非空时常驻：「t3 重试超限，等待决策 -> [挂起] [换人] [通知用户] [去对话]」（[12](12-http-api.md) 代答路由；「去对话」聚焦输入框并预填上下文摘要）。needs_user 任务同样横幅展示。

### 视图一：概览

- 目标全文（折叠）、阶段时间线（草案→批准→运行→完成）、进度条、当前并行执行数。
- 任务文件夹（D12）：路径展示 + [查看文档]（只读预览 README/合同/笔记，FR-40）+ 复制路径。
- 恢复报告卡（冷恢复后首次展示对账结果，[10](10-checkpoint-recovery.md) 10.4.3）。
- 快捷操作：暂停团队 / 停止团队（二次确认）/ 归档。

- 头像：React SVG 渲染（[14](14-avatar-system.md)）；点击大图预览 + 「编辑头像」（简化编辑器）/「重摇」。
- 「人设」：打开人设编辑器（固定框架字段表单：角色定位/职责/风格/技能/纪律/执行提示，D13）；保存提示「下次唤醒生效」（FR-39）。

### 视图三：任务（核心）

分组列表（状态分组，可切「按状态/按依赖(DAG)」两布局）：

```
● 执行中(1) ────────────────────────────────
 t3 实现导出模块            ●in_progress  ⟳1/3
    槽：[研究员✔][工程师●][审校员◌][＋ 拖入成员]   依赖 t1 ✔
    [执行线路 ▸] 站点 2/3 · 14:00起 · 6条记录
● 待指派(2) ────────────────────────────────
 t4 集成联调   依赖 t3 ◌      [指派成员…]
 t7 补充图表   无依赖          [指派成员…]
● 被阻断(1) t5 文档（上游 t3 挂起）…    ● 待决策(0) ● 已完成(3) …
                                            [+ 新增任务]
```

- 行内元素：状态点（色盲安全：点形+文字）、负责人头像小图、重试计数（⟳k/max）、依赖 chips（✔完成/◌未完成/⊘阻断）、操作（按 06.4 权限矩阵显隐）。
- 「指派成员…」-> MemberPicker 弹层（列出 ready 成员 + 当前负载 + 模型；D10 UI 指派）。
- **执行槽（D14）**：行内槽位即执行链站点渲染；空槽（虚线＋）为放置目标。从成员视图/卡片拖起成员头像时，合法槽高亮（staged 空槽 / ready 下一空站）。放置语义：staged = 写站点成员（遵守 6.4 链编辑规则）；ready = 指派，拖入成员≠链下一站时弹偏离确认（必填说明，06.7）；in_progress/终态槽禁用。槽聚焦 + Enter = MemberPicker（键盘等效）。
- 依赖布局：DAG 图（横向层级，仅任务节点+边；复用宿主图能力不可行时退化为缩进树，v0.2 接受缩进树）。

- 时间线节点：图标+文字+时间+操作者头像；失败红、成功绿、进行蓝。
- 抽屉底部快捷操作按状态与权限动态显隐（06.4）。

### 视图四：动态

事件流（[05](05-data-model.md) TeamEvent 渲染）：过滤芯片（任务/成员/决策/恢复），增量加载（afterSeq）；颜色语义与状态点一致。

### 成员对话框（D15/FR-42）

从成员卡「对话」或任务详情抽屉的站点头像进入；staged 阶段禁用（成员未派生）。

```
┌─ 成员对话框：研究员 ───────────── ●working · t3 ─┐
│  完整会话记录（宿主子代理视图 ↗）                  │
│ ┌──────────────────────────────────────────────┐ │
│ │ [指派] t3 · 站点 2/3（实现）        14:00 领队 │ │
│ │ [进度] 导出接口草稿（draft.ts）     14:07      │ │
│ │ [汇报] 站点 2/3 完成，产出…         14:23      │ │
│ │ [提问] 验收口径：要覆盖超长输入分支吗？ 14:25    │ │
│ │        ↳ [去答复]（聚焦输入框并预填上下文）      │ │
│ │ [用户] 需要，重点测超长与空输入      14:27 你    │ │
│ └──────────────────────────────────────────────┘ │
│ [输入框………………………………………] [发送]                │
└──────────────────────────────────────────────────┘
```

- 时间线来源：双向邮箱消息 + 该成员执行线路 progress 事件按时间合并（dialog 路由增量拉取，[12](12-http-api.md)）。
- 发送语义：成员空闲 -> 投递并 followup 唤醒；执行中 -> 入邮箱、本轮结束后送达（输入框上方提示「执行中，将在本轮结束后送达」）；对话框内不提供打断按钮（打断走成员卡「停止」）。
- 消息徽标：指派/汇报/进度/提问/答复/用户六类；成员提问高亮并附「去答复」快捷操作。
- 边界：对话框只做消息交互；状态变更（指派/取消/改派）仍走任务卡与抽屉（双入口写由同一状态机 + 团队锁兜底，12.3）。
- 成员侧协议：用户直发消息（user_message）作为高优先级上下文对待；超出合同范围的指令礼貌拒绝并转问领队（17 Q11）。

## 13.4 staged 计划编辑器（FR-31）

批准前的全屏弹层（从卡片「审阅计划」或横幅进入）：

- 左：成员表（名称/角色/模型路由/人设（编辑入口）/头像预览；增删改；模型选择器复用宿主模型目录）。
- 右：任务表（主题/依赖（多选）/执行链（站点序列编辑：成员 + 阶段说明）/验收/幂等说明；增删改、拖拽排序仅影响展示）+ 依赖关系缩进树预览。
- 底部：影响摘要（将派生 N 成员 / M 任务 / 预计并行度）+「确认并启动团队」主按钮 +「返回修改」（带留言，走 return 路由终止规划轮次）+「放弃计划」（二次确认，discard 路由）。
- 领队「宣布计划就绪」后编辑器进入待审态（领队侧锁定编辑权，用户仍可改；改动即时落盘并通知领队）。

## 13.5 交互细节与状态规则

| 规则 | 实现 |
|---|---|
| 破坏性操作二次确认 | 删除任务/取消进行中/停止团队/放弃计划/删除团队：宿主确认弹层 |
| 进行中任务只读 | 详情抽屉隐藏编辑入口，仅显示取消/改派（06.4） |
| 越权操作前置拦截 | 操作按钮按权限矩阵显隐；服务端仍强校验（12 路由 409 + hint） |
| 乐观更新最小化 | 仅按钮禁用态；真相以 ≤1s 轮询回填；失败回弹 + toast |
| 长内容折叠 | 合同/汇报默认折叠 3 行，展开全文；执行线路每尝试默认折最后 3 事件 |
| 空态引导 | 无团队：引导语 + 「/eteams 你的目标」示例；无成员任务：提示指派 |
| 停留时长提示 | working >30min 显示 ⏱；awaiting_decision 横幅显示已等待时长 |
| 拖拽不可用/无障碍 | 执行槽可聚焦，Enter 打开 MemberPicker；拖拽仅为增强交互（D14） |
| 对话框忙碌发送 | 执行中发送显示「本轮结束后送达」；消息必达（邮箱至少一次 + 补投） |
| 快捷键 | 面板 Esc 关闭；任务列表 j/k 移动、Enter 展开（对齐宿主习惯） |
| 无障碍 | 全部交互可键盘达；状态双编码（色+形+文）；aria-live 播报关键事件（完成/失败/决策） |

## 13.6 文案与国际化

- 文案表（zh/en）进 `locales.ts`，接入宿主 locale 服务实时切换（模式同参考实现）；状态文案表见 [06](06-task-lifecycle.md) 6.8。
- 时间格式跟随宿主（相对时间：<1min 刚刚 / <60min N 分钟前 / 否则 HH:mm）。
- 面板标题、空态、错误 hint 全部双语；工具渲染文本（对话流）由服务端按当前 locale 生成。

## 13.7 性能与体积预算

- 面板首屏渲染 <100ms（快照就绪后）；轮询解析 <10ms（100 任务规模）。
- 客户端 bundle 增量 <150KB gz（含头像数据资产；vendored 形状数据压缩后估算 <80KB，见 [14](14-avatar-system.md)）。
- 轮询降频：面板不可见（document.hidden）时暂停；恢复时立即一次。

# 16 测试与验收

## 16.1 测试策略总览

| 层 | 工具 | 覆盖对象 | 运行时机 |
|---|---|---|---|
| 单元测试 | vitest | 状态机、锁、原子写、重试阶梯、恢复重放、头像种子、交接包组装 | 每次 commit |
| verify 脚本（离线组合） | node 脚本（伪 runtime） | 工具全流程、协议边界、路由契约、冷恢复 | 每次 build 后 / CI |
| API 冒烟 | 真实 desktop profile 会话 | defineTool/exec.agent/startContinuable/followup 真实行为 | 每里程碑 |
| GUI 手工清单 | 人工 | 面板交互、主题、locale、恢复实验 | 里程碑 DoD |

单测纪律：`model/`、`state/`、`runtime/retry.ts` 的核心逻辑必须纯函数化/可注入（伪时钟、伪 fs、伪 subagent），单测不碰真实子代理与真实定时器。

## 16.2 单元测试清单（核心用例）

**状态机（06）**
- 全部合法迁移逐条断言；非法迁移抛 transitionError（含 from/to）。
- blocked 物化与解除：上游 suspended -> 下游闭包物化；解除 -> 回原状态；环外任务不受影响。
- 编辑矩阵（06.4）逐格断言：13 状态 × 6 操作。
- 依赖写入查环：构造环 -> 拒绝并返回环路径。

**持久化（09）**
- atomicWriteText：正常路径 / rename EPERM 三连 -> 降级直写成功 / 全失败抛错。
- 崩溃窗口：事件新快照旧 -> 重放一致；快照新日志旧 -> resynced 标记。
- 半行截断：events/inbox 尾部半行 -> 截断 + 标记。
- 锁重入与串行：并发 20 个事务 -> version 单调且无交错。
- team.json 损坏 -> 从 events 重放重建。

**重试与升级（08）**
- 3 连败 -> awaiting_decision；retryable=false 直接升级。
- reassign 清零 retryCount 并记 note；resume 不清零。
- 退避序列：base*2^(k-1) 抖动区间；nextRetryAt 持久化。
- 三决策各自的状态副作用（suspend 传染 / reassign 换人 / needs_user）。

**执行链（06.7）**
- 站点完成（非末站）-> ready + 游标+1 + stage_completed；末站 -> completed；中间站完成不解锁下游依赖。
- advance 默认取链下一站；无链任务 advance 报错；偏离未带说明被拒，带说明成功并记 chain.deviated。
- 站点推进清零 retryCount；链编辑规则（未开始可改/开始后仅追加）逐条断言。

**任务文档与人设（D12/D13）**
- docs 渲染幂等：同一状态渲染两次结果一致；状态变更后 contract.md 同步；notes.md 已有内容永不覆盖、缺失时创建。
- 人设框架校验：未知字段拒绝；默认模板按角色生成；唤醒摘要包含修改后字段。

**断点续行（10）**
- attemptToken：吊销后 progress/complete/fail 全被拒（错误含「所有权已变更」）。
- 冷恢复对账：running 团队 + working 成员（伪子代理可续/不可续两分支）-> reattached / 换成员交接包。
- 邮箱补投：未读消息在唤醒前先投且幂等（重复投递去重）。
- 交接包组装：含前序尝试关键事件、changedPaths 并集、最终建议栏。

**头像（14）**
- 种子确定性：同 seed -> 同 option -> 同 SVG 字符串（跨端：Node 与 jsdom 渲染一致）。
- 必选类别覆盖；未知形状 id 前向兼容。
- randomOption 分布抽样（每类别命中所有形状的频率 >0，simple 过滤生效）。

## 16.3 verify 脚本（离线组合校验）

伪 runtime（实现 SubagentRuntime 接口：spawn 返回假 childId、followup 记录消息、interrupt 记号）驱动完整剧本：

1. **黄金路径**：建队(staged) -> 加 2 成员 -> 建 3 任务(t1<-t2<-t3 依赖) -> 批准 -> 指派 t1 -> claim -> progress×2 -> complete -> 领队收到 report -> 指派 t2 -> … -> 全完成 -> 汇总。断言：每步事件序列、快照版本、邮箱内容、任务板输出。
2. **失败升级剧本**：t2 三连败（伪成员按脚本失败）-> 决策 suspend -> t3 blocked、t4（无依赖）照常完成。
3. **改派剧本**：t2 进行中改派 -> 旧 token 更新被拒 -> 新成员 claim 收到交接包。
4. **运行中编辑剧本**：新增 t5、修改 t2 合同、删除 t1（被依赖 -> 拒绝）、取消进行中 t3。
5. **冷恢复剧本**：黄金路径中途导出状态目录 -> 新建 store 实例 recovery() -> 断言对账结果与补投。
6. **多团队剧本**：建 A、建 B（A 自动 paused）-> 切回 A -> 归档 B（只读断言）。
7. **执行链剧本**：两站任务：站1完成 -> ready+游标+1 -> advance 站2 -> completed（下游解锁）；偏离分支：advance 时站2成员忙碌 -> assign 偏离（无 note 被拒，带 note 成功留痕）；双指派：站1成员同轮收到下一任务指派。
8. **人设与文档剧本**：update_member 改人设 -> 下次唤醒摘要含新内容；批准后 teams/ 目录齐备；删 contract.md -> 状态变更触发重渲染且 notes.md 完好。
9. **路由契约**：对 12 章每路由跑合法/非法/越权三态，断言状态码与错误体。

## 16.5 GUI 手工清单（里程碑 DoD 摘录）

**M4/M5**
- [ ] 卡片出现在团队创建后；点击头像打开成员会话；「打开面板」唤起浮动面板。
- [ ] 面板四视图数据与磁盘一致；任务详情抽屉执行线路完整（attempt 分组 + 事件时间线）。
- [ ] 1s 轮询：指派到面板反映可感知；面板隐藏时降频。
- [ ] staged 编辑器：成员(人设)/任务(执行链)增删改、批准启动、返回修改（规划轮终止）、放弃（二次确认）。
- [ ] 任务行/详情显示执行链站点（✔/●/◌），偏离记录可查；文档预览与磁盘一致。
- [ ] 成员卡人设编辑器：保存提示「下次唤醒生效」，实际唤醒消息生效。
- [ ] 执行槽拖拽：staged 拖入填链、ready 拖入指派（偏离弹确认且必填说明）、in_progress 槽禁用；槽聚焦 Enter 打开 MemberPicker（键盘等效）。
- [ ] 成员对话框：时间线含指派/进度/汇报/提问徽标；发送后空闲即唤醒、执行中显示「本轮结束后送达」；「完整会话记录」跳转正常。
- [ ] UI 指派：选成员 -> 任务行负责人更新 -> 领队收到系统通知（对话可见）。
- [ ] 越权操作按钮不出现；直接调路由被 409 且 hint 可行动。
- [ ] 亮/暗主题、中/英切换正常；状态色盲安全（去色验证）。

**恢复实验（M3 DoD，最重要）**
- [ ] 成员执行中停止（打断）：attempt paused -> 领队消息续行 -> 同 attempt resumed，成员记得之前进度（对话可验证）。
- [ ] 杀进程实验 A（成员执行中）：重启 -> 重开会话 -> 恢复报告 -> 显式确认续行 -> 无重复副作用（核对 changedPaths 与产物）。
- [ ] 杀进程实验 B（重试等待中）：退避定时器按 nextRetryAt 重建，不提前不丢。
- [ ] 杀进程实验 C（staged 阶段）：草案完整，可继续编辑批准。
- [ ] 领队停开窗重开：未读 report 补投，领队不「失忆」。

**M6 头像 / M7 多团队**
- [ ] 成员创建即有头像；重摇/编辑落盘且各处一致；重启后不变。
- [ ] 切换团队：A 停驻、B 激活；切回 A 续行；归档只读。

## 16.6 最终验收（v0.2 发布门槛）

对照 [01](01-goals.md) 1.6 成功判据：

1. **3 分钟新用户体验**：`/eteams` -> 目标 -> staged 清单 -> 批准 -> 执行 -> 汇总，全程无文档依赖。
2. **破坏性恢复演练**：10.8 三杀两停全过（录屏存档）。
3. **失败升级演练**：构造必败任务，验证 3 次自动重试 -> 决策横幅 -> 三选择各自结果。
4. **执行链演练**：三站任务沿链推进 + 一次显式偏离留痕 + 完成即续派（成员无空转）+ 面板拖拽完成一次指派与一次偏离确认；任务文件夹 README/合同/笔记与面板一致。
5. **多团队演练**：两团队切换/归档/隔离断言。
6. **质量门**：单测全绿；verify 9 剧本全过；typecheck 零错；体积/性能预算实测达标（[13](13-ui-design.md) 13.7）。
7. **文档同步**：实现与本 docs 集偏差为零或已回写文档（README 决策记录追加变更）。
